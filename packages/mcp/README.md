# @aaqiljamal/visual-editor-mcp

stdio MCP server exposing eight tools (selection + pins with source context, propose/apply/revert, CSS writers, browser highlight, pin resolution) to Claude Code, Cursor, Codex and any MCP client.

Part of [visual-editor](https://github.com/The-Design-Alchemist/visual-editor) — point at an
element in your running app, edit it visually or hand it to your coding agent with the exact
source location attached. Install and usage: the
[README](https://github.com/The-Design-Alchemist/visual-editor#readme) and
[INSTALL.md](https://github.com/The-Design-Alchemist/visual-editor/blob/main/INSTALL.md).
